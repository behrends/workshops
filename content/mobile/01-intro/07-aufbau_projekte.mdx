## Projekt in Android Studio erstellen und ausführen

Wir erstellen zunächst ein neues Android-Projekt für 
eine Beispiel-App für Todos, die wir gemeinsam im Live
Coding erstellen wollen. 

- Android Studio öffnen und neues Projekt erstellen
- Template „_Empty Activity_“ auswählen und `Next` klicken
- Name der App eingeben (z. B. `TodosAndroid` passend zum Framework) 
- Speicherort (_Save location_) anpassen und `Finish` klicken
- Warten bis das Projekt erstellt und geladen ist
- App im Emulator oder auf dem Gerät starten (grüner Play-Button)

<Callout>
Hinweis für Dozent (optional für den Kurs): 

- Im Terminal das Projekt mit `git` versionieren.
- Referenz-App: https://github.com/behrends/TodosAndroid
</Callout>

## Aufbau eines Android-Projekts

<Callout>
Früher war Java die Hauptprogrammiersprache für Android-Apps. Seit einigen Jahren wird Kotlin empfohlen. Aktuelle Dokumentation und neue APIs werden fast ausschließlich für Kotlin bereitgestellt.
</Callout>

Es wird ein kurzer Überblick der wichtigsten 
Dateien und Konzepte in Android Studio gegeben:

- `MainActivity.kt` definiert eine `Activity`, die als Einstiegspunkt für das UI der App dienen kann. Eine Activity kann mehrere Screens enthalten. Die Funktion `onCreate` wird beim Erstellen der Activity automatisch von Android ausgeführt. Dort wird u. a. das UI mit `setContent` festgelegt (bei Jetpack Compose).
- `@Composable`-Funktionen definieren das UI bei Jetpack Compose. Sie beschreiben die Darstellung einzelner UI-Elemente bis hin zu vollständigen Screens.
- Das Verzeichnis `kotlin+java` enthält den Kotlin- und Java-Code, u. a. `MainActivity.kt`. Im Dateisystem liegt dieser standardmäßig unter `app/src/main/java`, was in der `Project`-Ansicht nachvollzogen werden kann.
- Das Verzeichnis `res` (kurz für *resources*) enthält Ressourcen der App, die kein ausführbarer Code sind (z. B. Bilder, Texte und Übersetzungen).
- `manifests/AndroidManifest.xml` beschreibt wichtige Bestandteile und Eigenschaften der App, u. a. Berechtigungen und welche Activity beim Start über das Launcher-Icon geöffnet wird (oft `MainActivity`). Im Dateisystem liegt die Datei unter `app/src/main/AndroidManifest.xml`.
- Die beiden Dateien `build.gradle.kts` unter `Gradle Scripts` enthalten die Build-Konfiguration. Die Projektdatei legt übergreifende Einstellungen fest, während `app/build.gradle.kts` insbesondere die Android-Konfiguration und Abhängigkeiten des App-Moduls definiert.
- `gradle/libs.versions.toml` verwaltet zentral die Versionen und Definitionen von Bibliotheken und Gradle-Plugins, die in den `build.gradle.kts`-Dateien verwendet werden.
