# Flutter: Wetter-App

In diesem Crashkurs entsteht eine ähnliche Wetter-App wie in der
[Android-Lektion](../02-android), diesmal mit Flutter und Dart:
Eine Liste von Städten, und nach Antippen einer Stadt deren aktuelles
Wetter. Zuerst mit Fake-Daten, am Ende mit echten Daten von
[Open-Meteo](https://open-meteo.com), angebunden mit einem Coding Agent.

Die Schritte orientieren sich an der Android-App. So lassen sich die
Konzepte direkt mit Compose vergleichen.
