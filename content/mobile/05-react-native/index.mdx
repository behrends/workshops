# React Native: Wetter-App

In diesem Crashkurs entsteht dieselbe Wetter-App wie in der
[Android-Lektion](../02-android) und der
[Flutter-Lektion](../04-flutter), diesmal mit React Native, Expo
und TypeScript: Eine Liste von Städten, und nach Antippen einer Stadt
deren aktuelles Wetter. Zuerst mit Fake-Daten, am Ende mit echten Daten
von [Open-Meteo](https://open-meteo.com), angebunden mit einem Coding
Agent.

Die Schritte orientieren sich an der Android- und der Flutter-App. So
lassen sich die Konzepte direkt vergleichen.

<Callout type="info">
  Der Code liegt auf GitHub:
  [behrends/WeatherReactNativeTIF24](https://github.com/behrends/WeatherReactNativeTIF24).
  Jeder Schritt hat einen eigenen Tag (`schritt-00` bis `schritt-11`).
  Mit `git checkout schritt-05` lässt sich jeder Zwischenstand ansehen,
  der Link „Änderungen“ auf den folgenden Seiten zeigt den Diff eines Schritts.
  Nach dem Klonen einmal `npm install` ausführen.
</Callout>

<Callout type="warning">
  Expo erscheint etwa dreimal im Jahr in einer neuen SDK-Version, React
  Native noch häufiger. Im Live-Coding kann deshalb etwas anders aussehen
  oder nicht klappen. Bei Tutorials und Videos auf das Datum und die
  SDK-Version achten!
</Callout>
