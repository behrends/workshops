# Material 3

<DocsOnly>
Zum Schluss der Feinschliff: Die Karte im Wetter-Screen hat bisher eine
feste Farbe (`Color(0xFFBBDEFB)`) und feste Schriftgrößen. Im Dark Mode
ist ihre Schrift auf dem hellen Hintergrund kaum lesbar, weil das
`Scaffold` die Textfarbe an den dunklen Hintergrund anpasst.
</DocsOnly>

## Theme statt fester Werte

Material 3 liefert ein Theme mit Farben und Schriften und fertige Bausteine wie `Card`.

- `MaterialTheme.colorScheme`: Farben statt `Color(0xFF…)`
- `MaterialTheme.typography`: Schriftgrößen statt `fontSize = …sp`
- `Card`: Fläche mit Hintergrund und abgerundeten Ecken

<SlideBreak />

```kotlin
Card(
    modifier = modifier.fillMaxWidth().padding(16.dp),
    colors = CardDefaults.cardColors(
        containerColor = MaterialTheme.colorScheme.primaryContainer,
    ),
) {
    Column(/* ... */) {
        Text(text = city.name, style = MaterialTheme.typography.headlineMedium)
        // ...
    }
}
```

<DocsOnly>
In `CurrentWeatherCard` ersetzt die `Card` die selbst gebaute `Box` mit
`background`. Den Innenabstand bekommt jetzt die `Column`. Die neue
Funktion `CurrentWeatherCard`:

```kotlin filename="ui/WeatherScreen.kt"
@Composable
fun CurrentWeatherCard(
    city: City,
    weather: CurrentWeather,
    useCelsius: Boolean,
    modifier: Modifier = Modifier,
) {
    Card(
        modifier = modifier
            .fillMaxWidth()
            .padding(16.dp),
        colors = CardDefaults.cardColors(
            containerColor = MaterialTheme.colorScheme.primaryContainer,
        ),
    ) {
        Column(
            modifier = Modifier
                .fillMaxWidth()
                .padding(24.dp),
            horizontalAlignment = Alignment.CenterHorizontally,
        ) {
            Text(text = city.name, style = MaterialTheme.typography.headlineMedium)
            Text(text = weather.condition.emoji(), fontSize = 72.sp)
            Text(
                text = formatTemperature(weather.temperature, useCelsius),
                style = MaterialTheme.typography.displayLarge,
            )
            Spacer(modifier = Modifier.height(16.dp))
            Row(modifier = Modifier.fillMaxWidth()) {
                Text(
                    text = "Wind: ${weather.windSpeed.roundToInt()} km/h",
                    style = MaterialTheme.typography.bodyLarge,
                )
                Spacer(modifier = Modifier.weight(1f))
                Text(text = weather.condition.label(), style = MaterialTheme.typography.bodyLarge)
            }
        }
    }
}
```

Neue Imports: `Card`, `CardDefaults` und `MaterialTheme` aus
`androidx.compose.material3`. Die Imports von `background`,
`RoundedCornerShape` und `Color` werden nicht mehr gebraucht; *Optimize
Imports* (⌃ ⌥ O bzw. Ctrl+Alt+O) räumt sie auf.

Nur das Emoji behält eine feste Größe, weil es im Theme keinen passenden
Schriftstil dafür gibt. Die `Card` setzt passend zur Hintergrundfarbe
auch die Textfarbe (`onPrimaryContainer`).
</DocsOnly>

## Dark Mode und Dynamic Color

Weil Farben und Schriften aus dem Theme kommen, funktioniert der Dark Mode automatisch.

```kotlin
@Preview(showBackground = true)
@Preview(showBackground = true, uiMode = Configuration.UI_MODE_NIGHT_YES, name = "Dark Mode")
@Composable
fun WeatherContentPreview() { /* ... */ }
```

<DocsOnly>
Zwei `@Preview`-Annotationen an derselben Funktion erzeugen zwei
Previews, hier eine helle und eine dunkle. `Configuration` kommt aus
`android.content.res.Configuration`.

Die ganze Datei nach diesem Schritt:

// Stateful: holt den Zustand aus dem ViewModel
@Composable
fun WeatherScreen(
    city: City,
    modifier: Modifier = Modifier,
    viewModel: WeatherViewModel = viewModel(),
) {
    val uiState by viewModel.uiState.collectAsStateWithLifecycle()
    WeatherContent(
        city = city,
        uiState = uiState,
        modifier = modifier,
    )
}

// Stateless: zeigt nur an, was es bekommt (dadurch auch in der Preview nutzbar)
@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun WeatherContent(
    city: City,
    uiState: WeatherUiState,
    modifier: Modifier = Modifier,
) {
    // UI-Element-State: bleibt im Composable, gehört nicht ins ViewModel
    var useCelsius by rememberSaveable { mutableStateOf(true) }

    Scaffold(
        modifier = modifier,
        topBar = {
            TopAppBar(
                title = { Text(text = city.name) },
                actions = {
                    UnitToggle(useCelsius = useCelsius, onToggle = { useCelsius = !useCelsius })
                },
            )
        },
    ) { innerPadding ->
        when (uiState) {
            WeatherUiState.Loading -> CenteredBox(Modifier.padding(innerPadding)) {
                CircularProgressIndicator()
            }

            is WeatherUiState.Success -> CurrentWeatherCard(
                city = uiState.city,
                weather = uiState.weather,
                useCelsius = useCelsius,
                modifier = Modifier.padding(innerPadding),
            )

            is WeatherUiState.Error -> CenteredBox(Modifier.padding(innerPadding)) {
                Text(text = uiState.message)
            }
        }
    }
}

@Composable
fun CenteredBox(modifier: Modifier = Modifier, content: @Composable () -> Unit) {
    Box(modifier = modifier.fillMaxSize(), contentAlignment = Alignment.Center) {
        content()
    }
}

@Composable
fun UnitToggle(useCelsius: Boolean, onToggle: () -> Unit, modifier: Modifier = Modifier) {
    TextButton(onClick = onToggle, modifier = modifier) {
        Text(text = if (useCelsius) "°C" else "°F")
    }
}

@Composable

            Spacer(modifier = Modifier.height(16.dp))
            Row(modifier = Modifier.fillMaxWidth()) {
                Text(

                    style = MaterialTheme.typography.bodyLarge,
                )
                Spacer(modifier = Modifier.weight(1f))
                Text(text = weather.condition.label(), style = MaterialTheme.typography.bodyLarge)

        }
    }
}

Ab Android 12 passt *Dynamic Color* die Farben sogar an das
Hintergrundbild des Geräts an. Die Vorlage schaltet das in
`ui/theme/Theme.kt` bereits ein (`dynamicColor: Boolean = true`).
