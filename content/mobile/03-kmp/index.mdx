# KMP: Wetter-App

Mit Kotlin Multiplatform (KMP) und Compose Multiplatform läuft die
Wetter-App aus dem Android-Teil auch auf dem iPhone. Dazu kopieren wir
den Code fast unverändert in ein neues KMP-Projekt.

<Callout>
  **Dauer:** etwa 60 Minuten, kein ganzer Vorlesungsblock. Das Thema
  schließt direkt an den Android-Teil an oder füllt die restliche Zeit
  eines Blocks.
</Callout>

<Callout type="info">
  Der Code liegt auf GitHub:
  [behrends/WeatherKMPTIF24](https://github.com/behrends/WeatherKMPTIF24).
  Jeder Schritt hat einen eigenen Tag (`kmp-00` bis `kmp-04`).
  Mit `git checkout kmp-02` lässt sich jeder Zwischenstand ansehen,
  der Link „Änderungen“ auf den folgenden Seiten zeigt den Diff eines Schritts.
  Ausgangspunkt ist der Tag `schritt-10` der Android-App.
</Callout>
